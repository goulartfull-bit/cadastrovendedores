# Gestão Agente Autorizado

Portal público para cadastro de vendedores, revisão de informações e geração das planilhas Plan 5 + Plan 6, SGT3 e NetSales.

## Site

Após a ativação do GitHub Pages, o sistema ficará disponível em:

https://goulartfull-bit.github.io/cadastrovendedores/

## Privacidade

Os cadastros são armazenados somente no navegador utilizado. Para sincronização entre celular e computador será necessário conectar o portal a um banco de dados online.

O formulário público não contém senhas nem dados pessoais preenchidos no código-fonte.
